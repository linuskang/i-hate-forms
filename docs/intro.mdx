# i-hate-forms

**i-hate-forms** is a tiny registry of headless utility components built on top of [react-hook-form](https://react-hook-form.com/). It exists because wiring forms together is tedious, repetitive, and—let's be honest—annoying.

Instead of copy-pasting the same boilerplate every time, you get a small compound component that handles state, validation, and submission while you bring whatever UI you want.

## What it is

- A drop-in `<Form>` component that wraps `react-hook-form`.
- Sub-components for titles, descriptions, fields, and submit buttons.
- Zero styling opinions: use shadcn/ui, Base UI, or plain HTML inputs.
- TypeScript-first, so your form values are inferred everywhere.

## What it is not

- A validation library (bring your own resolver, like Zod).
- A styled component library.
- A replacement for `react-hook-form`—it is a thin wrapper around it.

## Quick example

```tsx
import { Form } from "@/registry/form"
import { Input } from "@/components/ui/input"
import { Button } from "@/components/ui/button"

export function ContactForm() {
    return (
        <Form
            className="space-y-4"
            onSubmit={(values) => console.log(values)}
        >
            <Form.Title>Contact us</Form.Title>
            <Form.Description>We will reply within 24 hours.</Form.Description>

            <Form.Field name="email">
                <Input type="email" placeholder="you@example.com" />
            </Form.Field>

            <Form.Submit>
                <Button>Send</Button>
            </Form.Submit>
        </Form>
    )
}
```

That's the whole idea. The library wires the form, you style it.
